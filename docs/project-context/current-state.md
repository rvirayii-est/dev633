## Content architecture

Two collections in `src/content.config.ts`, both loaded with the `glob` loader and
validated with Zod.

- `learnings`: title, description, published, updated, category, tags, draft
- `projects`: name, description, status, technologies, github, website, featured,
  order, draft

Categories are a fixed enum defined in `src/data/site.ts`. Drafts render in dev and
are excluded from production builds by the filter in `src/utils/content.ts`.
