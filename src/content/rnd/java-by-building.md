## What it is

Java by Building is a project-based course for beginners, including TESDA trainees, and a reference for
instructors. Instead of learning syntax in isolation, you build one application that evolves every week
until it is a real, deployable service you can show to an employer.

The step-by-step lessons are on this site: [start the course](/course). The code, tests and reference
solutions are in the [open-source repository](https://github.com/rvirayii-est/java-by-building).

## How it is built

- **Spec first.** A written specification and curriculum drive every lesson; a lesson is done when its
  tests pass and its checklist is ticked.
- **Everything runs.** CI compiles and runs every code example and every reference solution.
- **Milestones preserved.** Each lesson's solution extends the previous one, and seven milestones (M1 to M7)
  are tagged in Git so you can follow the application's evolution.
- **Free tools only.** JDK 21, Git and any editor; Maven comes through the bundled wrapper.

## The application's path

Console stock report, interactive menu, domain model, file persistence, database with transactions,
Spring Boot REST API, authentication and roles, then Docker, deployment, monitoring and a capstone.
