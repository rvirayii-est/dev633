## 2. Plain-English explanation
In lesson 33 the server answered with comma lines (`Rice 25kg,1250.50,12,OK`). A phone app would have to *parse* that text itself, and would break the day somebody adds a column. The world agreed on one text format for data instead: **JSON** (JavaScript Object Notation, said "jay-son"). Every language can read it. Java, JavaScript, Python and your phone app all speak it.

### JSON in two minutes
```json
{
  "name": "Rice 25kg",
  "price": 1250.50,
  "quantity": 12,
  "onSale": false,
  "supplier": null,
  "tags": ["staple", "25kg"]
}
```
Only six kinds of thing exist:
| Kind | Example | Notes |
|---|---|---|
| object | `{ "name": "Rice" }` | `{ }` with `"key": value` pairs separated by commas; **keys are always in double quotes** |
| array | `[1, 2, 3]` | an ordered list; can hold any kind |
| string | `"Rice 25kg"` | **double quotes only**; `\"` for a quote inside, `\n` for a new line |
| number | `1250.50`, `12`, `-3` | no quotes; no `1,250` with a comma, no leading zeros |
| boolean | `true`, `false` | lower case |
| null | `null` | "nothing here" |

No comments, no trailing comma after the last item (`[1, 2,]` is broken), no single quotes. Money is a **number** with its decimals (`1250.50`), not a string.

### Jackson: Java to JSON and back
**Jackson** is the standard Java library for JSON. Its main class is `ObjectMapper`:
```java
ObjectMapper mapper = new ObjectMapper();
String json = mapper.writeValueAsString(product);              // serialise
Product back = mapper.readValue(json, Product.class);          // deserialise
```
A Java **record** is the perfect partner: its components (`name`, `price`, ...) become the JSON fields, and nothing else. Jackson matches names, so the JSON field `reorderLevel` goes into the record component `reorderLevel`.

Two things need setting up once, in `Json.java`, and the lesson shows why:
- **Dates.** Jackson does not know `LocalDateTime` until you add the `jackson-datatype-jsr310` module, and by default it writes dates as lists of numbers. We switch that off, so a date is the standard text `2026-03-01T09:30:00`.
- **Money.** We read decimals as `BigDecimal` (never `double`, lesson 20) so `98.50` stays exactly `98.50`, and we write them as plain numbers (`1250.50`, never `1.2505E+3`).

By default Jackson also **refuses a field it does not know** (when reading into a record). That is useful: the typo `reorderLvl` gives a `400` with a message instead of silently doing nothing.

Dependencies enter the course here for the first time since H2. The root `pom.xml` imports the **Spring Boot BOM** (a list of library versions that are known to work together), so the lesson's `pom.xml` names `jackson-databind` and `jackson-datatype-jsr310` and never a version. Spring Boot uses the same Jackson from lesson 36 on.

### Why DTO records and not the domain classes
You could write `mapper.writeValueAsString(sale)` for the domain `Sale`. Do not. `JsonTest` shows what happens:
- `Sale` holds a `Discount`, an **interface** whose implementations have no fields. Jackson cannot write it: `No serializer found for class NoDiscount`. The API would crash.
- `Customer` would be written with **every getter**: the phone number, the loyalty points, even `walkIn` (from the helper method `isWalkIn()`). Nobody decided to publish the phone number. Add a `getPassword()` next month and it is on the internet.

A DTO (`SaleResponse`) lists exactly what the API promises. The domain can change without breaking any client, and nothing leaks by accident. Requests get DTOs too: `CreateProductRequest`, `UpdateProductRequest`, `ReceiveStockRequest`, `CreateSaleRequest`. The reader of a request body is no longer written by hand: `Body` from lesson 34 is **deleted**, and `Json.convert(body, CreateProductRequest.class)` does the same job and more.

### The whole API, in plain Java
Now all the pieces fit:
```
curl --HTTP--> JsonServer ---Map---> ShopApi ---> ShopService ---> repositories ---> H2
   (JSON text)   (reads JSON,         (routes, rules,    (lessons 30-31)
                  writes JSON)         status codes)
```
`JsonServer` is about 40 lines of real work: read the body and turn it into a `Map` (`Json.readObject`), call `ShopApi.handle`, write the `ApiResponse` as JSON with the right status and headers. `ShopApi` itself did not need to change much: the rules and the status codes are lesson 34's. This is a **complete REST API for the shop with no framework**. It works. Next lesson's question is: *how much of this code do we still want to write?*

## 7. Common mistakes and troubleshooting
| Symptom | Cause | Fix |
|---|---|---|
| `JsonParseException: Unexpected character ('''...` | Single quotes in JSON (`{'a': 1}`) | JSON allows only double quotes |
| `Unexpected character ... expecting double-quote to start field name` | A trailing comma, or a key without quotes | Remove the last comma; put keys in `"quotes"` |
| `InvalidDefinitionException: Java 8 date/time type ... not supported by default` | The `jsr310` module is not registered | `addModule(new JavaTimeModule())` (already in `Json`) |
| Dates written as `[2026,3,1,9,30]` | `WRITE_DATES_AS_TIMESTAMPS` is on | `disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)` |
| Prices written as `1.2505E+3` | `BigDecimal` printed in scientific form | `enable(WRITE_BIGDECIMAL_AS_PLAIN)` |
| `Unrecognized field "x" ... not marked as ignorable` | The JSON has a field the record does not have (often a typo) | Fix the name. Do not switch the check off just to make an error go away |
| `Cannot construct instance of ... no Creators` | A normal class with no default constructor | Use a record, or add a constructor Jackson can use |
| `No serializer found for class ...` | The object has no getters, or it is an interface implementation | Send a DTO record instead of the domain object |
| `curl` prints `{"status":400 ... "Malformed JSON"` for correct-looking JSON | The shell ate the quotes (common in `cmd` and PowerShell) | Use single quotes in Git Bash; in PowerShell write the JSON to a file and use `-d "@body.json"` (docs/SETUP.md) |
| `price` shows `98.5` instead of `98.50` | The value passed through a `double` somewhere | Keep `BigDecimal` all the way (lesson 20); never read money into `double` |
| Everything returns text instead of JSON in the browser | The `Content-Type` header is missing | `JsonServer` sets `application/json`; a client reads that header to decide how to parse |
